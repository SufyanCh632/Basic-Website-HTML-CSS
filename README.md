# Basic-Website-HTML-CSS
Landscape & City Discovery Landing Page
A responsive landing page concept designed to showcase breathtaking landscapes and urban destinations like Tokyo and Toronto. This project features a modern navigation layout and a structured grid for content delivery.

## Project Structure
The project is built using standard web technologies:

HTML5: Used for the semantic structure of the page.

CSS3: Linked via style.css for layout and design (external file).

Google Fonts: Utilizes the 'Roboto' font family for a clean, modern aesthetic.

## Key Features
Navigation Bar: Includes a logo/icon, links for Home, Region, and City, and a dedicated menu icon for mobile responsiveness.

Hero Section: A descriptive area focused on geophysical landforms, including a "Discover" call-to-action button.

City Cards: Specific sections highlighting "Tokyo" and "Toronto" with brief descriptions of their beauty.

Responsive Meta Tags: Includes the viewport meta tag to ensure the site renders correctly across different device sizes.

## Setup Instructions
File Organization: Ensure your directory contains the index.html file and a style.css file.

Images: Create an images/ folder and include the following assets:

icon.png (Site logo)

menu.png (Mobile menu toggle)

Viewing: Open index.html in any modern web browser to view the layout.
